# YuvaIntern Portal Description — Week2

**Word count: 248**

This Week 2 submission develops the Week 1 work into a visual account of transaction and fraud patterns. It reuses the cleaned training data and the stratified training/validation split; it does not redo data cleaning, use test labels, or train a model. The visual analysis examines the class imbalance, transaction amount exposure and risk, relative time windows, ProductCD and card-category combinations, and selected numerical feature relationships. Seven charts are included, with captions and findings intended to help a reviewer understand both what each plot shows and why the pattern may matter operationally.

The analysis records that fraud is uncommon, at approximately 3.50% of training rows, so raw transaction counts and accuracy-like summaries need context. One amount-decile view shows the top amount decile representing 45.4% of the aggregate transaction amount and a 5.14% observed fraud rate. ProductCD and card6 combinations show substantially different observed rates: ProductCD H in the top amount decile has a 39.05% rate in a small group of 630 records, while ProductCD C with credit card type has a 16.68% rate among 22,002 records. These are descriptive rates, not causal effects or guaranteed future performance. Relative time-window plots are explicitly interpreted as dataset-order patterns rather than calendar-time trends. A numerical association plot highlights V258, while the project notes that missingness and coverage affect interpretation. The package contains the visualization script, chart PNGs, findings, metrics and verification evidence. It excludes source datasets and bulky intermediate tables so the work is suitable for review and public repository upload.
