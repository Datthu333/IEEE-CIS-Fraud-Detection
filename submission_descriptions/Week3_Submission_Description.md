# YuvaIntern Portal Description — Week3

**Word count: 239**

This Week 3 submission applies statistical tests to selected fraud-related differences using training observations only. It reuses the existing cleaned data and earlier descriptive findings rather than repeating broad exploratory analysis. The questions focus on transaction amount, ProductCD, card6, and the availability and observed values of V258. Mann–Whitney testing was used to compare amount distributions without relying on a normality assumption; a Welch t-test on log-transformed amounts provided a complementary comparison. Chi-square tests with effect sizes were used for categorical associations, and uncertainty intervals were reported where appropriate. Multiple comparisons were accounted for with Holm adjustment, and the report discusses assumptions and limitations in plain language.

The amount comparisons did not show evidence of a meaningful difference in this sample: the Mann–Whitney result had p=0.4354 and Cliff’s delta of −0.0036, while the Welch comparison of log1p amounts had p=0.4673 and Hedges’ g of −0.0067. In contrast, ProductCD was associated with fraud status in the observed training data (chi-square statistic 13,090.07; Cramér’s V 0.1665), and card6 also showed an association (chi-square statistic 4,726.84; Cramér’s V 0.1000). V258 availability differed by fraud status, and among records with observed V258 values, the distributions also differed substantially. These results describe association and do not establish that any feature causes fraud. The report includes the hypotheses, test statistics, adjusted p-values, effect sizes, supporting charts, verification output and reproducible source code. The package deliberately leaves original transaction records and all test data outside the repository.
