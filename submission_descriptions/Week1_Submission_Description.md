# YuvaIntern Portal Description — Week1

**Word count: 252**

This Week 1 submission establishes a clean, auditable foundation for the IEEE-CIS Fraud Detection project. The objective was to understand the supplied transaction and identity tables, preserve the original training and test boundaries, and prepare data for later analysis without discarding potentially useful fraud signals. The workflow recorded the source schemas, checked key integrity and duplicates, reviewed data types and missingness, and joined identity attributes to the corresponding transaction records with TransactionID. No training rows were removed as duplicates, and columns were not dropped solely because they had many missing values. Missing values in the model-ready version were handled through transformations fitted on the training-fit partition and applied consistently to the held-out partitions.

The training data contains 590,540 transactions and the test data contains 506,691 transactions. The target is isFraud and remains available only with training observations. For reproducible validation, training records were split with stratification using random_state 42, preserving the observed fraud rate of about 3.50% in both partitions. Identifiers and the target are kept separately from model features. This package contains the Week 1 report, source scripts, data-quality summaries, verification documentation, and the associated charts. It does not contain original CSVs, derived transaction tables, or private local paths. The work is intended to make later findings traceable: the report explains the cleaning decisions, while the scripts document how the processed outputs can be rebuilt when the authorized source files are supplied locally. Week 1 therefore provides a transparent starting point for the subsequent visualization, statistical testing, and model evaluation work.
