# YuvaIntern Portal Description — Week5

**Word count: 258**

This Week 5 submission brings the completed five-week IEEE-CIS Fraud Detection project into a consolidated report suitable for internship review. It reuses the cleaning and stratification record, Week 1 exploratory results, Week 2 storytelling charts, Week 3 hypothesis tests, and Week 4 validation metrics. The report describes the business problem and data, the end-to-end workflow, documented data-quality choices, visual and statistical findings, model comparison, practical implications, limitations, and future work. It includes 19 relevant charts from the previous weeks and references the scripts used to reproduce the work.

The project’s central modeling lesson is that fraud detection should be assessed with metrics that expose minority-class performance. In validation, the weighted gradient-boosting model achieved average precision 0.4218, recall 0.7239 and F1 0.2341, outperforming the weighted logistic regression model on these measures. The high false-positive count at the selected threshold is discussed as an operational review burden, while missed fraud remains a separate risk. Statistical tests indicate descriptive associations for several categorical features and V258, while amount comparisons did not show a meaningful difference under the reported tests. No causal claims are made. The report also explains that relative time fields do not identify calendar dates and that a single split cannot establish long-term production performance. The submission includes all five weekly reports, code, charts, supporting summaries, and these portal descriptions. It intentionally excludes raw datasets, credentials, local user paths, model predictions, and unnecessary binary artifacts. The accompanying README provides a concise project overview and manual guidance for reproducing the work when data is available in an authorized local environment.
